Photos

Words match anywhere in a photo's result, EXIF or file name. All terms must match. field:text contains · field=text exact · field>3, <, >=, <= compare numbers or dates · has:field has a value · -term excludes · "quotes" for spaces. Fields are result keys (category or the full classification.category), EXIF tags (exif.Model, DateTimeOriginal>2024), name and status. EXIF fields need read EXIF first; photos you open are read automatically.

Scenes

Words match anywhere in a scene's result. All terms must match. field:text contains · field=text exact · field>3, <, >=, <= compare numbers · has:field has a value · -term excludes · "quotes" for spaces. Fields are result keys (category or the full interpret.category), scene, start, end, duration (seconds), status and error.
